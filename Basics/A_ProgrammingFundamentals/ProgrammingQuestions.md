Q1. What is programming?

Answer:

Programming is the process of writing instructions for a computer to perform tasks or solve problems.

Q2. What is source code?

Answer:

Source code is a set of human-readable instructions written using a programming language, such as Java.

Q3. What is machine code?

Answer:

Machine code consists of instructions encoded for a specific processor architecture that the CPU can execute directly.

Q4. What is an algorithm?

Answer:

An algorithm is a finite, well-defined sequence of steps used to solve a problem.

Q5. What is a compiler?

Answer:

A compiler translates source code into another representation, such as bytecode or machine code, for execution or further processing.

Q6. What is an interpreter?

Answer:

An interpreter executes instructions by interpreting them, rather than relying solely on ahead-of-time translation to native machine code.

Q7. Does Java directly convert source code into machine code?

Answer:

Typically, Java source code is compiled into bytecode first. The JVM executes this bytecode using an interpreter and may use JIT compilation to convert frequently executed code into native machine code.
